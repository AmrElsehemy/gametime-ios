# Engagement and Difficulty

## Engagement model
Design five nested loops:

1. **Second-to-second** — input → motion → sound → haptic → visual reward.
2. **Round** — challenge → tension → solve → celebration → next/retry.
3. **Session** — levels → mastery → novelty → milestone.
4. **Daily** — daily challenge → streak → reward → return.
5. **Long-term** — progression → collections → events → seasons when justified.

## Difficulty principles
- Difficulty should not only rise; it should breathe.
- Introduce a mechanic, allow easy success, practice it, combine it, challenge it, then provide relief.
- Avoid long stretches of repeated difficulty with no novelty.
- Near-miss moments may naturally create desire to retry, but levels must not be secretly manipulated to manufacture monetizable frustration.

## Metrics
Track:
- completion rate by level
- attempts to win
- time to solve
- abandonment
- restart rate
- hint/undo usage
- booster usage
- session length
- levels/session

## Difficulty system direction
Future reusable capability may include:
- level difficulty metadata
- skill estimate
- dynamic hinting
- level variants
- generated puzzle difficulty scoring
- experiments

Do not build adaptive difficulty into v1 unless a shipped title proves the need.
