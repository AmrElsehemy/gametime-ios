# Game Time Autopilot Vision

## End state
Knowlly Games should operate like a small studio while requiring the owner mainly at strategic approval gates.

## Owner gates
1. **Build it?** — concept/game greenlight.
2. **Ship it?** — release candidate, store page, launch creative review.
3. **Scale it?** — retention/revenue/creative performance and budget decisions.

## Automatable workstreams

### Build
- code generation/scaffolding
- tests
- level validation
- replay regression
- performance checks

### Release
- versioning
- TestFlight upload
- screenshot generation
- metadata/release notes preparation
- App Store submission preparation

### Operate
- crash/issue monitoring
- anomaly detection
- level abandonment alerts
- ad/IAP failure alerts
- GitHub issue creation
- remote mitigation suggestions

### Grow
- gameplay capture
- Remotion creative generation
- captions/hooks
- social scheduling
- creative performance analysis
- paid campaign recommendations

### LiveOps
- challenge/event preparation
- reward-table simulation
- offer/event configuration

## Human-controlled areas
Never give unrestricted automation authority over:
- substantial ad spend
- pricing
- material economy changes
- privacy/legal changes
- first public release
- major redesigns
- sunsetting products

## Desired briefing
The owner should receive a concise portfolio brief with:
- live game health
- retention/revenue changes
- critical issues
- releases awaiting approval
- growth recommendations
- development status

Autopilot is a direction, not Day-1 scope. Ship games first and automate repeated pain as it appears.
