# LiveOps and Retention

## Principle
LiveOps is a capability, not a requirement for every title.

## Candidate features
- daily challenge
- daily reward
- forgiving streaks
- weekly challenge
- collections
- comeback rewards
- timed events
- event-specific rewards
- seasons and premium pass only for retained games

## Rollout order
1. Prove core retention.
2. Add daily challenge/streak where appropriate.
3. Add weekly/event content when content depth supports it.
4. Add pass/seasons only after repeated return behavior is proven.

## Remote operation
LiveOps configuration should be data-driven and controlled by the backend with:
- bundled defaults
- validation
- start/end timestamps
- game/version eligibility
- kill switches

## Do not
- make core play unavailable without a network
- make streak loss excessively punitive
- overload small puzzle titles with Candy-Crush-scale meta systems before retention exists
