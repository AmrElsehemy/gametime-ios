# Privacy, Identity and Accessibility

## Identity
Do not create a proprietary username/password system for v1.

Use:
- local profile/state
- Game Center for gaming identity, achievements, leaderboards and friend comparisons where useful
- cloud save only when justified

The game remains playable if Game Center is unavailable.

## Privacy
Privacy is a platform concern.

Design for:
- minimal data collection
- ATT only when required by actual tracking behavior
- third-party SDK privacy manifests and declarations
- clear privacy/support URLs
- reset/delete local data where appropriate
- no unnecessary personal account data

## Children / audience
Do not assume every colorful game is a Kids Category app. Decide deliberately per title because kids-focused distribution changes advertising/analytics/commerce constraints.

## Accessibility baseline
Where practical support:
- Reduce Motion
- sound toggle
- haptic toggle
- large touch targets
- high contrast
- color-independent state cues (shape/pattern/icon/outline)
- VoiceOver for non-canvas surfaces and where meaningful

Color should not be the only information channel in games that rely on matching or region identity.
